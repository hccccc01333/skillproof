# 中文版（V2EX / 即刻 / 知乎）

## 标题（选一个）

1. **我把 GUI agent 论文里没人跑的那个基线跑了：回放演示，100 分变 25 分**
2. **一次演示录下来，回放比大多数 agent 方法都好 —— 直到页面改版**
3. **我做了个录一次就能生成 skill 的工具，但真正值钱的是它测出来的三个数**

推荐 1：它给出可验证的具体数字，不靠形容词。

## 正文

先说结论，工具在后面。

几乎所有 GUI agent 的论文都拿「什么都不做」当对照，没有人拿**「把演示原样回放」**当对照 —— 而它是免费的、确定性的，并且在演示页上拿到 100/100，比我知道的任何方法都好。

然后页面改一次（顺手把测试钩子也去掉）：同一个任务，回放掉到 **25/100**。把回放强化一下（每个值都从当前页面重新读），**还是 25**。而从同一次演示里归纳出的 skill，两个页面都是 **100/100**，各三次。

另外三个数，都不好看，但都是量出来的：

1. **agent 说「完成了」，在没校验时 10 次里 10 次是假的**（实际 20～75 分）；有完成校验闸门的 18 次里 18 次是真的。评测表里没有 `finished` 这一列，等于在报假账。
2. **分数和运行会分家**：一组消融里 9 次运行 8 次 100 分，只有 5 次真的走到终点。中间那组把活干对了三次，却把 30 步预算跑光、从没声明完成 —— 而 rubric 读终态，给了三次 100。
3. **页面状态校验有一条边界，但不是大家以为的那条**：给它一个错一个字符的密码，agent 从页面上读走了真密码、登录、声明成功 —— 校验器**全绿**，因为页面确实对了，而且它一条 gap 都没声明。完成校验关得掉「页面最后对不对」，关不掉「你有没有按我说的做」。

仓库里有什么：录一次 → 归纳出 skill + 一个机器可校验的完成条件 → 在任意网页上跑；扰动阶梯；**十个被记录的 harness 故障**、**五种 verifier 失效模式**；每一份 run 文件，包括被隔离的。`python reproduce.py` 11 秒内重算页面上所有确定性数字，**不需要模型、不需要密钥** —— 我最希望有人去打破的就是这一条。

它不是什么：不是通用自动化产品。两个任务在我自己的 app 上、两个公开站点、N=3、大部分格子只有一个归纳模型。页面不变的时候，回放和 skill 打平 —— 那种场景请直接用脚本。
