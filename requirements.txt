# Runtime dependencies. Python 3.11+.
#
# Only two, and only one of them is a real dependency rather than a convenience:
#
#   playwright  drives the browser. Recording, replaying and executing all go
#               through it. Nothing works without it.
#   pillow      downscales evidence frames before they reach a model. Vision
#               cost scales with pixel area, and the induction could not finish
#               on an image-heavy request until this was implemented; the code
#               degrades to full-resolution if it is absent, which is why it is
#               listed as optional in spirit but installed by setup.sh.
#   openai      only needed to run induction. Everything else -- recording,
#               running an induced skill, replaying, scoring, and the whole
#               benchmark -- works without it.
# >=1.50 is a floor, not a preference: the `chromium-headless-shell`
# install target that setup.sh names does not exist in older releases, and
# `launch(headless=True)` uses that shell rather than the full browser.
playwright>=1.50
pillow>=10.0
openai>=1.30
